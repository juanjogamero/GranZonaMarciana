ANDROID / JAVA

Del aula al portfolio.

Gran Zona Marciana es una aplicación móvil construida con Java, Android SDK y Room sobre SQLite. Su arquitectura incluye entidades, DAO, servicios y actividades nativas. Gestiona ediciones, galas, noticias, solicitudes y puntuaciones.

La versión web es una representación independiente y estática para explorar la idea sin instalar un emulador. No ejecuta Android, no autentica usuarios reales ni comparte datos con la APK.
